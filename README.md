# Athletica

Bienvenue sur **Athletica** – Un projet sportif moderne.

## Description

Athletica est une application web conçue pour les passionnés de sport, les entraîneurs et les athlètes. Elle permet de suivre les activités, organiser des événements, et gérer les performances sportives grâce à une interface intuitive et réactive.

## Fonctionnalités principales

- Suivi des activités sportives
- Analyse des performances
- Tableau de bord interactif
- Interface moderne et responsive

## Composition technologique

- **HTML** (81,9%) : Structure principale de l’application
- **JavaScript** (11,3%) : Fonctionnalités interactives et dynamiques
- **CSS** (6,8%) : Stylisation et mise en page

## Installation

1. Clonez le dépôt :
   ```bash
   git clone https://github.com/Tx-diloxi/Athletica.git
   ```
2. Ouvrez le dossier du projet :
   ```bash
   cd Athletica
   ```
3. Ouvrez `index.html` dans votre navigateur.
